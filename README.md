# 🌍 TripTo

TripTo is a **full-stack travel companion web application** that helps users explore destinations, plan trips, and access real-time insights through intelligent suggestions and a seamless user interface.

## ⚙️ Tech Stack

- **Frontend:** React (Vite) + TailwindCSS  
- **Backend:** Node.js + Express  
- **Database:** Supabase (PostgreSQL)   
- **Language:** JavaScript (ES Modules)

---

## 🧠 Features

- Intelligent trip planning and location-based insights  
- Supabase backend for real-time and scalable data handling  
- Fully responsive and optimized user interface  
- Modular code structure for easy maintenance and extension
